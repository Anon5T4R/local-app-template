# Asset attribution

Every asset shipped in this repository is listed here (see the asset rules in `AGENTS.md`). No
asset may come from Adobe products. Add an entry in the same commit as the asset.
`cargo xtask assets` fails if any image, icon, font, sound or video file in the repository is not
matched by a path pattern in the first column (`*` = any characters except `/`; a trailing `/`
covers a whole directory), or if a licence file referenced in the Licence column is missing.
